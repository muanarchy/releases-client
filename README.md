# MuAnarchy client releases

Download-only repository for the MuAnarchy client mod `Main.dll`. Releases are published here by the build pipeline; there is no source code.

Files in each release: `main-full.zip` (everything for players) and `main.zip` (Main.dll only; the launcher uses it), plus checksums. Go to the [latest release](https://github.com/muanarchy/releases-client/releases/latest) for the download links and the change log; this page is updated automatically after the first release.
